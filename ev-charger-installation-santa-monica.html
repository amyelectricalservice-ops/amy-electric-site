Most Level 2 EV charger installations run $350-$900 for a straightforward garage install with existing 240V service nearby. If a 240V circuit needs to be run from your panel, add $200-$500. If a panel upgrade is needed, add $2,500-$4,500. We provide free estimates after a brief on-site inspection (30 minutes) with a detailed line-item breakdown so you know exactly what each part costs.

Most residential Level 2 installations take 2-4 hours for a straightforward install with existing 240V service nearby. If a new circuit needs to be run from the panel, add 1-2 hours. We schedule the installation once permits are approved and typically complete it in one visit.

Do I need a permit to install an EV charger in Santa Monica? ▾
Yes. All EV charger installations in Santa Monica require an electrical permit from the local building department. AMY Electric handles all permitting for you — we pull the permit, schedule the inspection, and ensure every installation meets current NEC and California Electrical Code requirements.
