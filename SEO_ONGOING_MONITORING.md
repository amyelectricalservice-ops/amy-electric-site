# AMY Electric SEO Ongoing Monitoring

This checklist is the operating routine for the recurring SEO tasks in the six-month roadmap.

## Weekly Search Console review

Run each Monday in Google Search Console:

1. Review clicks, impressions, CTR, and average position for the previous 7 and 28 days.
2. Check the Performance report for service, city, geo-service, and blog page groups.
3. Review indexing and page-experience reports for new errors.
4. Record notable changes, queries, and pages in the team's reporting log.

## Monthly AI citation check

Use the query set and scoring worksheet in `SEO_AI_VISIBILITY_BASELINE.md`. Run the same prompts in ChatGPT, Claude, and Perplexity, then record:

- Whether AMY Electric is mentioned
- Which page or domain is cited
- Whether the citation is accurate
- The answer quality and visibility score

Do not describe a brand as cited unless the result was observed and recorded.

## Quarterly content freshness review

Every quarter, review the highest-impression and highest-conversion pages first:

- Confirm pricing and service descriptions are still accurate.
- Check permits, utility references, and code guidance against current official sources.
- Replace stale examples and update `dateModified` only when substantive changes are made.
- Recheck internal links, schema, canonical URLs, and sitemap dates.
- Keep claims evidence-based; do not add invented reviews, customer identities, or project results.
