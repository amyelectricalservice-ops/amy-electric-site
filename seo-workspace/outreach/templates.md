## Guardrails for all three drafts

- **No invented contacts, names, or handles.** Each draft is addressed
  `[Contact Name]` / `[Directory Team]` on purpose. Contacts verified in this session
  are in `outreach/prospects.md` with the URL each was taken from; anything else gets
  found before sending, not guessed.
- **No volume claims, no rankings, no client counts.** AMY can state credentials,
  service area, and what it publishes. It cannot state "we're the top-rated EV
  installer in LA" — there is no data behind that and it invites exactly the kind of
  scrutiny a licensing claim does not.
- **Paid is labelled paid.** AAGLA Business Council membership, chamber tiers, and
  SRAR sponsorship all cost money. Buy them as business-development spend, and if a
  listing is sponsored, say so in the copy.
- **Personalise per recipient.** One specific, checkable sentence about *their* page
  or publication beats three paragraphs about AMY.
- **One follow-up maximum**, seven days later, then stop.

### What was deliberately left out

- **A competitor-comparison draft.** Comparison pages convert well for some niches,
  but a public "AMY vs <competitor>" page aimed at link outreach would read as
  picking a fight in a small LA market, and there is no backlink data available to
  prove it would earn links. If a comparison asset is ever wanted, it belongs on the
  site as buyer guidance (page-to-page insurance/credential comparisons), not as an
  outreach email.
- **A "broken link building" draft.** No backlink/crawl data is available this
  session (OpenSEO's DataForSEO backend returns HTTP 401 — see `prospects.md`), so a
  broken-link campaign cannot be targeted honestly yet.
