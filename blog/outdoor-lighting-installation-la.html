Code Requirements

Los Angeles Outdoor Electrical Code

  • All outdoor outlets must be GFCI-protected
  • Weatherproof while-in-use covers required
  • Underground conduit: 18" line-voltage, 6" low-voltage
  • Fixtures must be wet or damp-rated
